# Brand

Everything visual about Fourier comes from this folder. The mark, the three
colours, and a generator that turns them into every favicon, app icon and
social card in the repository.

> This is an early palette. It will change. When it does, edit
> [`brand.mjs`](brand.mjs) and the CSS variables at the top of
> [`apps/web/app/globals.css`](../apps/web/app/globals.css), run `pnpm brand`,
> and every asset follows.

## The mark

Three bars, the middle one lifted — a spectrum, which is the whole joke of the
name. Drawn in a 64×64 box:

| bar | x | y | width | height | radius |
| --- | -- | -- | ----- | ------ | ------ |
| 1 | 15 | 14 | 6 | 42 | 1 |
| 2 | 25 | 6 | 9 | 42 | 1 |
| 3 | 38 | 14 | 13 | 42 | 1 |

The ink occupies `15 6 36 50`, so the mark is **18:25** — taller than it is
wide. It is never stretched, recoloured per-bar, outlined, or reordered.

## Palette

| | hex | oklch | where |
| --- | --- | --- | --- |
| **Onyx** | `#141414` | `oklch(0.1913 0 0)` | icon tiles, dark backgrounds |
| **Platinum** | `#EEF0F2` | `oklch(0.9542 0.0034 247.86)` | light tiles, type on onyx |
| **Mint** | `#00FFAE` | `oklch(0.8833 0.1959 161.25)` | the accent, on onyx |
| Mint ink | `#00A069` | `oklch(0.62 0.147 161.25)` | the accent, on paper |

Mint is the only colour with an opinion, and it has one problem: `#00FFAE` at
oklch L=0.88 sings on onyx and all but vanishes on white. So anything that has
to stay legible on a light background — a chart line, the active nav icon, the
mark in a lockup on paper — uses **mint ink**: the same hue and chroma taken
down to L=0.62. In the app that choice is automatic, via `--brand-mint-legible`.

In CSS the palette is available as `--brand-onyx`, `--brand-platinum`,
`--brand-mint`, `--brand-mint-ink` and `--brand-mint-legible`, and as Tailwind
utilities: `bg-brand-onyx`, `text-brand-mint`, `text-brand-mint-legible`.

## Which mark where

The dashboard wears mint on onyx. The example app wears onyx on platinum, so
that two tabs open side by side during development are never confused for one
another.

and `FourierLockup` (mark plus wordmark, in the app's own Geist).

## The wordmark

Geist SemiBold, tracked −0.02em, with the mark standing at 0.86em — a little
taller than the capitals — and a 0.32em gap measured ink to ink.

The SVG lockups set that as **live text**, so they are correct inside the app
and approximate anywhere Geist is missing. Where no font stack can be trusted —
a README, a social card, anything that leaves the app — use the baked PNGs.
Those are set in Helvetica Neue, the closest face macOS ships to Geist, which
is also why `pnpm brand` skips them off macOS and leaves the committed copies
alone. Everything else in the list above is pure Node and builds anywhere.

## Using it

- Give the mark clear space of at least one bar-width on every side.
- Don't put the mint mark on white, or the onyx mark on onyx. Reach for mint
  ink and platinum respectively.
- The smallest the mark should appear is 16px tall. Below 32px the rasteriser
  snaps every edge to the pixel grid so the bars stay 1:2:3 rather than
  blurring into a picket fence — which is also why `favicon.ico` carries hand-
  tuned 16, 32 and 48px renders rather than one scaled image.
- Don't rebuild the lockup by hand. Use the component or the SVG.

## Regenerating

```bash
pnpm brand
```

No dependencies, no install step. It prints every file it wrote.

## A note on the name

The AGPL covers Fourier's source. It is not a grant of the Fourier name or
mark — if you run a fork, give it your own. Keeping the mark is fine when
you're pointing at this project.
